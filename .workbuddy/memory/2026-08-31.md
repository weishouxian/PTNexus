## 定时发种预检查限制跳过逻辑
- 需求：定时发种队列任务遇到预检查限制错误时，立即继续发下一个种子，不再干等到下个发种间隔。
- 实现（`server/internal/service/migrationflow/publish_queue.go` + `types.go` + `bootstrap/app.go`）：
  - 复用「目标站点已存在」的调度器续跑机制：`notifyQueueExistingTorrent` 泛化为 `notifyScheduledSeedContinue(task, reason)`，hook 重命名为 `SetPublishQueueScheduledSeedContinueHook` / `publishQueueScheduledSeedContinueHook`。
  - `executePublishQueueTask` 中两个 `isPreCheck && limitReached` 分支（预检查限制/标签限制）合并为一个，失败记 `pre_check_limit` 后调用 `notifyScheduledSeedContinue` 触发 `sched:<taskID>` → scheduler 立即处理下一个种子。
  - 附带行为变化：「发布前禁转站点限制」（同为 pre_check+limit_reached）以前走无意义重试 3 次，现在也归入 pre_check_limit 立即失败并续跑。
  - 队列级网段做种数限制（`CheckDownloaderGateStats` requeue 等待限制解除）不受影响，仍是等待语义。
- 验证：`go build ./...`、`go vet`（migrationflow/bootstrap/scheduledseed）通过；相关包无测试文件。
- 状态：本地改动，未提交、未部署。

## 动画类型按季集重判（解析种子信息）
- 需求：解析种子信息时，若源站类型是动画，按标题组件「季集」重判类型：有值 → 电视剧（category.tv_series），无值 → 电影（category.movie）。
- 实现（`server/internal/service/processing/persist/`）：
  - `seed_draft.go`：新增 `CorrectAnimationTypeBySeasonEpisode()`（命中 category.animation/动画/动漫 时按季集改写 d.Type）、`isAnimationTypeValue()`、`SeasonEpisodeFromTitleComponents()`。
  - `fetch_finalize.go`：`FinalizeFetchedSeed` 在 `BuildTitleComponents` 之后、`CompleteAndMapTags` 之前调用纠偏并输出「迁移-类型纠偏」日志（torrent_id/标题/季集/前后类型）。
  - 新增 `seed_draft_test.go` 覆盖 7 种场景 + 季集提取，全部通过。
- 影响面：动画源种子的 standardized type 不再是 category.animation；发布时目标站分类将走电影/电视剧映射（CBG 不受影响，它按 tag.动画 + 自身季集分流）。季集识别依赖标题 Sxx(Eyy) 模式，纯集号无 Sxx 的动画标题会判为电影。
- 验证：`go build ./...`、`go vet ./internal/service/processing/...`、`go test ./internal/service/processing/persist/...` 通过。
