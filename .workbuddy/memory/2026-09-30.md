## 副标题季集补全（电视剧 / 动漫整季合集）

- 需求：电视剧 / 动漫的**整季合集**种子，副标题补写「第x季 全y集」。口径经用户多轮确认：
  - 写入时机：**处理阶段写进 `seed_parameters.subtitle`**（入库值即带，前端预览与发布随之生效）。
  - 写法固定「第3季 全12集」（阿拉伯数字）。
  - 拼装：**插到副标题第一个空格之后**；副标题无空格或为空 → 追加到末尾。
  - 副标题已含「全X集」→ 完全不动（幂等）；副标题已含季号但无「全X集」→ 只补「全y集」。
  - **单集种子（S03E05 等）不加**，只有整季包 / 合集才加。整季包判定 = 识别到的集数 ≥ 总集数（本地集数或种子文件集数，二者均需 > 1）。
  - 季号 x：标题组件「季集」→ 主标题 / 种子名 → 简介「◎季　　数」；都取不到则只写「全y集」。
  - 集数 y：简介「◎集　　数」优先 → 本地集数 → 种子文件集数。
  - 动漫一并处理（标准化分类 `category.animation` / `tagging.HasAnimationTag` / 季集特征，任一命中）。
- 落点：`processing/persist/seed_draft.go` → `SeedDraft.CompleteAndMapTags`，紧跟 completion 判定与 `DetectEpisodeTag` 之后。抓取链与抓取修复链都会经 `FinalizeFetchedSeed` 走到这里，此时 `d.Title / Subtitle / TitleComponents / TorrentFileNames / completion` 全部在手。
- 实现：新增 `processing/tagging/subtitle_season.go`，导出纯函数 `EnrichSubtitleWithSeasonEpisode(SubtitleSeasonEpisodeInput) (string, string)`。发布侧无需改动（`publish_target.go` 直接取 `uploadData["subtitle"]`）。
- ⚠️ 电视剧判定刻意用**严格季集特征** `\bS\d{1,2}(E\d{1,3})?\b|第X季`，没有复用 `hasEpisodeToken`——后者含「第N期」，会把综艺误判成剧集。
- ⚠️ 加工发生在 `ExtractRawTagsFromSubtitle` 之后，标签提取不受影响；但重算链会因副标题含「全X集」判为完结（符合语义，源站本就这么判）。
- 历史已入库种子不会回填：重算链 `RecomputeAndPersistTagsIfNeeded` 只写 tags / type / updated_at，不碰 subtitle。
- 验证：临时测试 11 例全绿（标题 Sxx、已含全X集、已有季号、单集、无空格、电影、本地集数兜底、中文季号「第三季」、副标题为空、无季号、动漫标签+简介季数），验完删除，备份于 `.workbuddy/tmp/test-backup/zz_tmp_subtitle_season_test.go.1790698993`。`go build ./...`、`go vet ./internal/service/processing/...`、gofmt 均通过。

## 修订：副标题已有季号时「全y集」紧贴季号之后
- 反馈：老卫指出 `简繁英字幕 第3季` 应变成 `简繁英字幕 第3季 全12集`，而不是按原「插到第一个空格后」得到 `简繁英字幕 全12集 第3季`。
- 改动（仅 `processing/tagging/subtitle_season.go`）：新增 `insertAfterSeasonToken(subtitle, fragment)`，用 `reSubtitleSeasonToken`（`第X季`/`Sxx`）定位季号结束位置，把「全y集」贴到其后；`EnrichSubtitleWithSeasonEpisode` 中**仅当副标题已含季号**时走这条路径，其余情况仍走原 `insertSeasonEpisodeFragment`（第一个空格后 / 无空格追加末尾）。同步更新函数文档注释第 6 条。
- 验证：临时测试 8 例全绿（季号在末尾/开头/中间、Sxx、中文「第三季」、已含全X集不动、无季号走原路径、副标题为空），含幂等复跑；`go build ./...`、`go vet ./internal/service/processing/...`、gofmt 全过。测试备份 `.workbuddy/tmp/test-backup/zz_tmp_subtitle_season_test.go.<ts>`。
- 教训：季集片段的插入位置规则要按「副标题内是否已有季号」分叉，不能统一按空格切。
