## yemapt 发种站点接入（阻塞，待用户提供浏览器抓包）
- **结论**：yemapt（YemaPT, www.yemapt.org）是 UmiJS SPA + 自研 REST API 站，cookie `auth`/`b_auth` 鉴权，API 基址 `/api/`，**非 NexusPHP**。不能走 `PublishPublic()` + `configs/<site>.yaml` 流程，需新增专属 adapter `sites/yemapt.go` 并在 `engine/engine.go` 的 switch 注册 `case "yemapt"`。
- **前置核查**：`sites_data.json` 已有 yemapt 元数据（nickname=YemaPT, base_url=www.yemapt.org）；`engine.go` 无该 adapter（走 default）；`configs/` 无 `yemapt.yaml`。`server/internal/service/publish/publisher/sites/` 下现有 ~21 个 adapter，但**全部是 NexusPHP 公共表单站点**（实现 `publicSitePublisher` 接口，最终仍走 `PublishPublic` 的 `takeupload.php`），无自研 API 型先例。
- **卡点（静态逆向失败）**：前端 chunk `static-ui.yemapt.org/8df01b5e/static/js/*.async.js` 在 CDN 对非浏览器请求返回 SPA fallback HTML（真实浏览器能加载，但脚本工具只能拿到 index.html）；后端对所有错误请求（错误端点/缺字段）统一返回 `{"success":false,"showType":0}` 模糊错误。POST 试错无法反推字段。
- **下一步需用户**：Firefox 打开发种页 `https://www.yemapt.org/#/torrent/add` → F12 → Network（勾 XHR/fetch）→ 点"发布种子" → 把那条发种 API 请求的 **URL / Method / Request Headers / Request Body(Form Data)** 贴出。据此精准实现 adapter。
- **风险**：实现后无法实机验证（真实发种有风险），需用户在 webui 给 yemapt 填 cookie 后试发排错。
