# 2026-09-02 工作日志

## 爱玲(aling)站点接入发种功能
- 目标：将爱玲(pt.aling.de)作为发种目标站，实现发种功能
- 现状：sites_data.json 已有 aling 元数据(site=aling, base_url=pt.aling.de, group=-alingWEB)，但缺 configs/aling.yaml，导致 LoadSitePublishConfig("aling") 失败
- 方案：爱玲是标准 NexusPHP，走 engine.go default → PublishPublic()，无需专属 adapter，也无需改 engine.go 路由
- 抓取发种页：用户提供 c_secure_pass cookie(单个即可通过校验)，写 Python 脚本带 cookie GET upload.php，解析出完整表单结构
- 关键差异(爱玲 vs 其他 NexusPHP)：
  - select 字段名带 [4] 后缀：medium_sel[4]/codec_sel[4]/standard_sel[4]/team_sel[4]/source_sel[4]
  - 分类仅 4 类：401=电影 402=电视剧 404=纪录片 405=动画
  - 无音频编码(audiocodec_sel)字段
  - 有 tags[4][] 标签：12=国语 13=粤语 10=其他中国方言 6=中字 1=禁转 14=Dolby Vision 4=DIY 7=HDR
  - 用 pt_gen 接收豆瓣链接(无独立 url/dburl 文本框)
  - 匿名用 NexusPHP 标准 uplver(anonymous.go 自动兜底，无需配置)
  - 文件字段=file，表单 action=takeupload.php
- 产出：新增 server/configs/aling.yaml(upload_file_field + form_fields + source_parsers + mappings[type/medium/video_codec/resolution/source/team/tag])
- 验证：go test LoadSitePublishConfig("aling") 通过，所有字段/分类映射断言正确
- 后续：用户需在 webui 给爱玲填 cookie 使其成为目标站(ListSourceAndTargetSites 按 cookie 非空区分源/目标站)

- 目标：把"为 NexusPHP 站点接入发种功能"的工作流沉淀为可复用 skill，便于以后接入更多站点

- skill 范围选择理由：高度项目特定(依赖 server/configs、LoadSitePublishConfig、sites_data.json 等 PTNexus 特有结构)，放 project-level 而非 user-level
