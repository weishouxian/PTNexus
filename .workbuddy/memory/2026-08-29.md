## 详情弹框宽度/滚动「不生效」根因复盘
- 用户反馈改了 900px + 滚动样式后仍无变化 → 两个根因：
  1. **运行的是构建产物 `webui/dist`**：前端改动必须 `pnpm run build` 后才会进入打包结果，否则页面仍是旧版（宽度 prop 自然不变）。已重新 `pnpm run build` 生成新 dist。
  2. **el-dialog CSS 真实 bug**：Element Plus 弹框默认 `--el-dialog-margin-top: 15vh`，与 `max-height: 90vh` 相加 105vh 超出视口，弹框被顶出屏幕、内部也滚不动。修正：把 `.resource-detail-dialog` / `.resource-edit-dialog` 的 `--el-dialog-margin-top` 改为 `5vh`（5+90=95vh 适配视口），并给 header 加 `flex-shrink:0`、body 维持 `flex:1; min-height:0; overflow-y:auto`。
- 后续用户反馈 100% 缩放下仍占满屏 → 进一步加 `overflow:hidden !important` + `!important` 强制覆盖 + margin-top 收到 4vh、max-height 85vh。

## 资源信息详情/编辑弹框高度修复（最终生效方案，第三次）
- 之前在 `.el-dialog` 上套 `display:flex + max-height + overflow:hidden` 仍被 Element Plus 内部布局顶破、整框占满屏。
- **最终方案（ResourceInfoView.vue scoped style）**：弹框保持默认 block 布局，只给 `:deep(.el-dialog__body)` 设 `max-height: calc(90vh - 60px - 60px)` + `overflow-y:auto`；`--el-dialog-margin-top` 收 5vh 并加 `margin-bottom:5vh!important`；header 加底边框。header/footer 不进滚动区。
- 教训：el-dialog 高度约束用「body max-height 滚动」比「整框 flex + max-height」可靠。改完必须 `pnpm run build`（dist 之前被占用导致用户看到的仍是旧码）。
